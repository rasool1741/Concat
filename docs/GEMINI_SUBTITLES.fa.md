# زیرنویس هوشمند فارسی با Gemini در Concat

این قابلیت داخل شیت **Captions** است و موتور محلی Whisper را حذف یا جایگزین نکرده است. با سوییچ «موتور» بین «روی این کامپیوتر» و «Gemini» جابه‌جا می‌شوید.

## ۱. تنظیم کلید API
1. از Google AI Studio یک کلید Gemini API بگیرید.
2. در Concat شیت Captions را باز کنید، سوییچ «Transcribe this clip's voice» را روشن کنید و موتور را روی **Gemini** بگذارید.
3. کلید را در فیلد «کلید API» بچسبانید (با نقطه‌چین نمایش داده می‌شود) و **ذخیره کلید** را بزنید.
4. **آزمایش اتصال** را بزنید. اگر موفق بود، فهرست مدل‌های قابل استفاده پر می‌شود.

کلید فقط در محل امن سیستم‌عامل ذخیره می‌شود (Credential Manager ویندوز، Keychain مک، keyring لینوکس). در `settings.json`، فایل پروژه، لاگ یا کد منبع نوشته نمی‌شود و در پیام‌های خطا هم دیده نمی‌شود. با «حذف کلید» پاک می‌شود.

## ۲. ساخت زیرنویس فارسی
1. کلیپ دارای صدا را روی تایم‌لاین انتخاب کنید و شیت Captions را باز کنید.
2. موتور: Gemini. مدل: `gemini-3.5-transcribe` (زمان‌بندی کلمه‌به‌کلمه دارد). زبان گفتار: «فارسی» یا «Auto».
3. پیام زیر دکمه نشان می‌دهد چند درخواست و چند مگابایت صدا به سرویس Google فرستاده می‌شود. فقط صدای همان کلیپ فرستاده می‌شود، نه ویدئو.
4. **Generate captions** را بزنید. زیرنویس‌ها به‌صورت کلیپ‌های متنی روی تایم‌لاین می‌نشینند و با یک Undo برمی‌گردند.
5. «Placement» و «Size» جای و اندازه را تعیین می‌کنند. برای فونت، رنگ، حاشیه و پس‌زمینه از پریست‌های متن (دسته‌ی Persian) یا پنل Text استفاده کنید.

### نحوه نمایش (Appearance)
کل جمله، ساخته‌شدن کلمه‌به‌کلمه، یک کلمه در هر لحظه، یا تایپ حرف‌به‌حرف. دو حالت اول فقط با زمان‌بندی واقعیِ کلمه‌ها کار می‌کنند؛ اگر مدل زمان کلمه ندهد، کل جمله می‌آید و زمان ساختگی ساخته نمی‌شود. هر جمله حداکثر ۶۰ قطعه می‌شود.

### حرکت (Motion)
Fade، Pop، Slide up و Scale in با دکمه‌ی «Apply to captions» روی همه‌ی زیرنویس‌های همان ردیف (ردیف عنوان انتخاب‌شده یا پرکارترین ردیف) اعمال می‌شود. این‌ها کی‌فریم‌های خودِ کلیپ‌اند و بعداً روی تایم‌لاین قابل ویرایش‌اند.

## ۳. ویرایش
متن، زمان شروع و پایان، برش، حذف، افزودن و Undo/Redo با همان ابزارهای تایم‌لاین و Text انجام می‌شود، چون هر زیرنویس یک کلیپ متنی عادی است.

## ۴. خروجی
- **Export SRT**: متن و زمان.
- **Export ASS**: فونت، اندازه، رنگ، حاشیه یا کادر، سایه، تراز و جای هر زیرنویس. آنچه ASS نمی‌تواند نگه دارد (گوشه‌ی گرد کادر، حاشیه کنار کادر، نرمی سایه، چرخش، کی‌فریم) در پیام خطا/هشدار گفته می‌شود و بی‌صدا حذف نمی‌شود.
- **ویدئوی نهایی**: از Export معمولی Concat؛ زیرنویس‌ها با همان موتور متن پیش‌نمایش (shaping فارسی، BiDi، نیم‌فاصله) روی تصویر رندر می‌شوند.

## ۵. Build برای ویندوز
پیش‌نیازها: Rust (نسخه‌ی `src/rust-toolchain.toml`)، CMake، ابزارهای C++ ویژوال استودیو و بسته‌ی FFmpeg 7+ shared (BtbN) با `FFMPEG_DIR`.
```
cd src
cargo build --profile app -p concat
```
یا از Actions مخزن: workflow به نام **Build app**.

## ۶. اجرای تست‌ها
```
cd src
cargo test -p concat-gemini -p concat-project -p concat-text
python ../scripts/locales.py --check
```
تست کامل پروژه: `cargo nextest run --workspace` (نیاز به FFmpeg و GPU).

## ۷. محدودیت‌های شناخته‌شده
- هایلایت رنگیِ «کلمه‌ی جاری» داخل یک خط پیاده نشده: موتور متن برای هر عنوان یک رنگ دارد و رنگ جداگانه برای یک کلمه نیاز به تغییر موتور متن دارد.
- سایه فقط روشن/خاموش است؛ میزان محوشدگی و جابه‌جایی سایه به مدل سند و موتور متن اضافه نشده.
- ترجمه و اصلاح با Gemini: منطق و تست‌هایش آماده است (`concat-gemini::lines`) اما هنوز در رابط شیت دکمه ندارد.
- ادغام دو زیرنویس و جست‌وجوی متن زیرنویس‌ها: ابزار ویژه ندارد؛ با ابزارهای تایم‌لاین انجام می‌شود.
- مدل `gemini-3.5-transcribe` با ارسال مستقیم صدا (inline) در سرور واقعی هنوز آزمایش نشده؛ اگر رد شود، باید آپلود فایل (Files API) اضافه شود.
- متن‌های رابط در ۲۳ زبان غیر از انگلیسی و فارسی فعلاً انگلیسی‌اند.
